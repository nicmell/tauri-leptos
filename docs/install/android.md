# Android

## Prerequisites

- Android Studio (or command-line SDK) with SDK, NDK, and JDK 17+
- Environment: `ANDROID_HOME` and `NDK_HOME` pointing at the SDK/NDK
- Rust targets:

```bash
rustup target add aarch64-linux-android armv7-linux-androideabi \
  i686-linux-android x86_64-linux-android
```

## Project generation

`src-tauri/gen/android/` is the Android Studio project generated by
`cargo tauri android init` and is **committed**, because it carries two
hand edits:

- `app/src/main/res/xml/network_security_config.xml` — allows cleartext
  http to `127.0.0.1`/`localhost` only. Required: the webview loads the
  app from the in-process axum server over plain http, and this file
  (unlike `usesCleartextTraffic`) also applies to release builds.
- `AndroidManifest.xml` — the `android:networkSecurityConfig` attribute
  referencing it.

Re-running `android init` can overwrite these edits — review the git
diff afterwards.

## Develop / build

```bash
cargo tauri android dev                       # emulator or connected device
cargo tauri android build --debug --target aarch64
cargo tauri android build                     # release (needs signing config)
```

Logs go to logcat with the app's tag:

```bash
adb logcat -s tauri-leptos
```

For release signing, follow the Tauri docs
(<https://v2.tauri.app/distribute/sign/android/>).
